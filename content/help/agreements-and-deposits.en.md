## Terms then agreement package

After you **Accept** an offer, the **Agreement** section moves to the top of the booking. Generate a single **PDF package**: a cover naming both parties, German controlling text beside the English convenience translation, numbered addenda as later pages, and a large **MUSTER** watermark on every page.

The cover includes Salon’s convenience disclaimer: Salon provides the package for the undersigned and is not a legal advisor. Download the PDF to review. Page footers include page numbers and a package fingerprint for tracking.

## Double opt-in sign

Each designated signer must:

1. Review the package PDF
2. Type the confirmation phrase exactly (`I agree` / `Ich stimme zu`)
3. Press **Sign agreement**

Both signers must complete this on the same package fingerprint before the booking confirms and calendars block.

**German text is controlling.** English is a labeled convenience translation.

## Signatures

Current e-sign uses the sandbox `ESignProvider` until a production provider is configured — treat signing as the product workflow, not a live QES claim.

## Deposits

Deposit status is tracked on the booking and is **independent** of confirmation. Salon **never holds or escrows funds**.
